# TV Home

A full-screen home page for a Hisense VIDAA TV. It shows prayer times all the time, along with a clock, the Hijri date and the weather. You control it with the TV remote.

- Open: https://theraouf.github.io/tv-home/
- Remote: press OK to open settings, use ▲▼ to pick a setting and ◀▶ to change it, and press BACK to save.
- Prayer times are calculated on the TV, so they work offline. The default is the UAE method (18.2° / 18.2°).
- Source: `src/` (run `node build.js` to produce `index.html`).
